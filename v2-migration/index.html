HAKUNA MATATA V2

Veri güvenliği kontrolü

Bu araç mevcut Hakuna IndexedDB verisini yalnız okur. Eski veritabanına yazmaz, temizlemez veya silmez.

Hazırlanıyor Legacy veri kontrol ediliyor.

Bu aşamada yapılanlar

  • hakuna-matata-db / app / state readonly okunur.
  • Blocks, görevler, borçlar, denemeler, sorular ve diğer tüm state alanları aynen snapshot'a girer.
  • State için deterministic SHA-256 üretilir.
  • Eski database otomatik olarak hiçbir zaman silinmez.
