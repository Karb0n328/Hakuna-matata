# GEES — YKS çalışma planlayıcısı

GEES, önceki Hakuna Matata uygulamasının yeni marka adıdır. Kullanıcı verileri, IndexedDB anahtarları ve eski yedek şemaları geriye dönük uyumluluk için korunur.

Ayarlar bölümündeki ChatGPT köprüsü arayüzden kaldırılmıştır. Öneri kutusu ve yeni alan adı geçişi geliştirme aşamasındadır.
